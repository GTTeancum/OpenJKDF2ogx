=JEDI KNIGHT MOD================================================

Title                   : JK HUD Revamp
Author                  : Quib Mask
Date                    : 2007/09/11

Because the JK HUD Revamp is a type of hack, other players do not need the same files in order to

* Modification Details *

Left HUD Window
Top Green Numeric Readout = Shields
Bottom Red Numeric Readout = Health
Left Vertical Red Gauge = Health (5 status levels + empty)
Center Green Gauge = Shields (10 status levels + empty)
Top Left Yellow Indicators = Super Shield Status (on)

Right HUD Window
Top Red Numeric Readout = Ammo
Bottom Red Graphical Readout = Mana (15 status levels + empty)
Right Vertical White Gauge = Fieldlight Status (off or on)
Center Green Indicators = Batteries (8 status levels + empty)

* Bugs *

Having 200 or more health will display a single tiny digit above the red health gauge.
Having 10 or more of an item will display invalid characters in the item selection UI.
Neither of these situations occur within the standard parameters of basic Jedi Knight.
